# Исправление совместимости AvilixLogger 2.1.35 с NeoForge 21.1.259

## Причина

Пользователь использует Minecraft 1.21.1 / NeoForge 21.1.259. В ранее выданный JAR попал диапазон `[21.1.265,)`: шаблон `neoforge.mods.toml` использовал переопределённый параметр версии стенда `neo_version` как минимальную версию запуска. Это ошибка выпуска; обновление загрузчика пользователю не требуется.

## Изменения относительно ранее выданной 2.1.35

- Сборка по умолчанию закреплена на NeoForge 21.1.259.
- Минимальная версия запуска выделена в `neo_version_range=[21.1.259,)`; переопределение версии компиляции её больше не повышает.
- `verifyObfuscatedJar` проверяет диапазон зависимости внутри конечного обфусцированного JAR, а не только шаблон.
- Версия мода остаётся 2.1.35, имя файла `avilixlogger-2.1.35.jar`. Игровой код и протокол не менялись.

## Проверки

- Полная компиляция, `testAsyncPipeline` (включая HTTP/сетевые проверки), `testCreatePreflight`, `verifyMixinSafety`, `verifyObfuscatedJar`, `compileCreateSmokeJava` на 21.1.259: успешно.
- Внутри конечного JAR прочитан TOML и проверен диапазон `[21.1.259,)`.
- Отдельная регрессия: `generateModMetadata -Pneo_version=21.1.265` сохраняет диапазон запуска `[21.1.259,)`; затем выполнена проверка JAR с настройками по умолчанию (21.1.259).
- Сравнение с ранее выданным файлом: все 1123 `.class` побайтно совпадают; единственное изменившееся содержимое ZIP — `META-INF/neoforge.mods.toml`. Нет добавленных/удалённых записей.
- Полный native Create-прогон на 21.1.259: `AVILIX_CREATE_SMOKE_OK`; штатное завершение и сохранение мира. Отрицательные сценарии намеренно проверяют ошибки сериализации, превышение бюджета и отмену.
- `RECOVERY_SCENE_MEMORY_RELEASE_OK`: снимок 8 MiB становится доступным для GC после завершения, блокировки освобождены.
- Синтетические серверные прогоны (60 тиков, 16 захватов/тик в baseline/candidate):

Это ограниченный синтетический стенд, показатели не описывают весь модпак с реальным онлайном.

Клиентский прогон на NeoForge 21.1.259 успешно завершён: `CART_GUI_CLIENT_OK`, `RECOVERY_GUI_NATIVE_OK`, `SERVER_LOG_GUI_NATIVE_OK`, `SERVER_LOG_FOLDER_OPEN_NATIVE_OK`. Проверены общий стиль/виджеты и границы на 320×240, 640×360, 960×540; передача diagnostics.log с точным содержимым и вызов открытия клиентской папки. Linux native opener проверялся через фиксирующий аргумент стендовый обработчик; это не тест Windows Explorer.

Профиль 972 кадров на программном OpenGL с лимитом 60 FPS: средний FPS 59.1, p95 интервала 18.16 ms, p99 27.64 ms, наблюдаемый heap 774.9 MiB. Это весь стендовый клиент; показатели не являются атрибуцией памяти одному Logger и не гарантируют FPS полного модпака.
