# Scorched Guns: дополнительная проверка 26.10.2026

Код и тесты: `86c8800bbfb802cfdef4a15cfb641af72b4308ff`, ветка `work/2.2.0-scguns-turrets-20261026`, исходная база `247b4a55be864d9a58252982b31455c880180e30`. Релизный JAR не подготовлен.

## Изменения

- Добавлен исторический источник турели: блок, позиция механизма, точное дуло/направление, владелец на момент выстрела. Владелец доступен отдельно и в поисковой сводке; он не подменяет человеческого actor.
- Native fire scope разделяет один неизменяемый контекст между дробинами; принимаются только успешные `addFreshEntity`. Подтверждённое попадание стрелы турели в блок проходит отдельным перехватом.
- `Shot.Version=2` добавлен для механизмов. Игроки продолжают использовать v1; обе версии сохраняются в NBT, журнале и подробностях базы.
- Native stop очищает Logger reload session и при уже отключённом сборе. В этой ветке нет нового снимка, synced-data read, публикации или tick-опроса.

## Локальные проверки

Java 21, NeoForge 21.1.244. Compile-only контракты взяты из предоставленных JAR, без их публикации и без сетевого поиска пользовательского состава. Для подготовки Minecraft использована отдельная локальная копия NeoForm Runtime с исправлением двух определений Java executable: окружение не возвращает `ProcessHandle.info().command()`. Сам Logger, игровые JAR и оригинал инструмента этим обходом не менялись; CI использует обычные инструменты.

Прошли `compileJava`, `compileCreateSmokeJava`, `testAsyncPipeline`, `testExactModpackPreflight`, `verifyMixinSafety`. Exact preflight проверил **155 mixin-контрактов**, из них **11 Scguns**, по **101 предоставленному target-классу**. Raw preflight не доказывает отсутствие всех transformed-конфликтов модпака.

Тесты истории проверяют защитные копии оружия и владельца, v1/v2 save/load и сжатый журнал, отрицательные координаты, точные углы/точку взгляда, поисковую сводку владельца, отказ от повреждённых данных и вымышленного человеческого actor.

Одинаковые сценарии выполнены **с предоставленным corefix 1.0.0 и без него**. Использован отдельный тестовый мир и loopback-порт. Контракт остаётся привязан к Framework 0.13.11, Curios 9.5.1, GeckoLib 4.9.2 из предоставленного набора.

Повторно прошли прежние проверки accepted/cancelled/empty/cooldown выстрела, дробовика с 26 дробинами, луча без projectile entity, урона/смерти игрока, snapshots, точного teleport и отказа от частичного rollback.

AuthCore **не включался и не обходился**. Production capture оставался отключённым (`accepted=0`, `adapterFailures=[]`). Native-поведение и отдельные ядра формирования записей проверены раздельно. Настоящая публикация залпа/урона/убийства в авторизованной игровой сессии и переход через GUI остаются производственной приёмкой.

## Незакрытый native-блокер

Обычная остановка ручного reload Boomstick воспроизводит исключение:

```text
C2SMessageReload.lambda$handle$0 → ReloadHandler.loaded(Player)
Attempted to load class net/minecraft/client/player/LocalPlayer
for invalid dist DEDICATED_SERVER
```

Прямой вызов клиентского обработчика присутствует в исходном байткоде Scguns 1.5. Он воспроизводится с corefix и без него. Logger его не добавляет и не подменяет поведение мода. Native stop успевает сбросить `RELOADING`, но пакет завершается исключением: этот сценарий **не считается успешным**.

Fixture распознаёт только это конкретное исключение из native lambda, явно выводит `SCGUNS_KNOWN_NATIVE_BLOCKER` и продолжает остальные независимые проверки. Любая другая ошибка остаётся `SCGUNS_NATIVE_FAILED`. Итог расширенного прогона — **`SCGUNS_COVERAGE_NATIVE_PARTIAL: knownBlockers=1`**. Старый `SCGUNS_NATIVE_OK` подтверждает только прежний набор проверок и не отменяет этот partial-статус. Один exit code Gradle не считается доказательством успешного gameplay.

## Повторение native-проверки

В `SCGUNS_SMOKE_MODS` оператор указывает отдельный каталог с точными JAR Scguns и обязательных зависимостей, при необходимости с corefix. Собственные исходники и секреты туда не добавляются. Нужен отдельный неавторизованный тестовый мир; fixture сам останавливает сервер.

```bash
./gradlew runServer -PscgunsSmoke -PscgunsSmokeMods="$SCGUNS_SMOKE_MODS" \
  -Pneo_version=21.1.244 -PcompatCreateVersion=6.0.10-281 \
  -PcompatAe2Version=19.2.18 -PcompatFrameworkVersion=1.21.1-0.13.11
```

Проверяются и stdout, и `run/logs/latest.log`. Обязательные отдельные результаты: `SCGUNS_TURRET_NATIVE_OK`, `SCGUNS_EXPLOSION_NATIVE_OK`, `SCGUNS_RELOAD_PACKETS_CHECKED`; partial/blocker не подменяется полным успехом.

## CI и дополнительные границы

Финальный прогон: [четыре серверных профиля и настоящий ClickHouse](https://github.com/Vlad-Ras/Logger/actions/runs/40240446981), [GUI](https://github.com/Vlad-Ras/Logger/actions/runs/40240447015). Все четыре серверных профиля, отдельная настоящая ClickHouse и GUI завершились успешно. После проверенной ревизии добавлена только документация; Scguns на CI отсутствует, поэтому игровой контракт подтверждается отдельными локальными native-прогонами, а не отсутствием этого мода в CI.

В предыдущем прогоне один профиль выявил зависимость старого теста falling-block timeout от случайного грунта после взрыва: native landing/placement мог происходить раньше timeout. Исправлена только fixture: перед спавном очищается блок под падающей сущностью. Нативная физика и код Logger не подменены.

Не закрыты native-блокер ручного stop, оставшиеся виды турелей/оружия/ловушек, поздний огонь без direct source, Sable-преобразования, авторизованный end-to-end бой и все 267 JAR модпака. Новых замеров MSPT/heap/allocations на production или ферме 8 пил + 8 активаторов + portable storage interface нет. Прежние 60 000 мкс/тик Observable не объявляются устранёнными.
