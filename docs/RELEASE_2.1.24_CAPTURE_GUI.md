# AvilixLogger 2.1.24 — переключение записи событий в GUI без перезапуска

Новая кнопка **«Запись событий»** находится справа в основном GUI логгера, рядом с «Настройки».

- Названия **12 категорий** соответствуют выпадающему фильтру «Тип».
- Страница показывает **состояние сервера**, а не локальную настройку клиента.
- Администратор с правом `avilixlogger.command.admin` может включать и выключать группы, а также выбрать «Включить все» / «Выключить все». Для открытия основного GUI требуется `avilixlogger.gui`.
- Изменения применяются **немедленно**, без перезагрузки игрового сервера. Данные сохраняются в **SavedData мира** `avilixlogger_data` и восстанавливаются при загрузке мира.
- Новая история, отключённая настройкой, **не записывается**, поэтому откатить эти новые события нельзя. Исторические записи и доступ к запросам/откатам ранее записанных событий не изменяются.
- Несколько администраторов видят актуальное состояние. Если страница устарела, сервер не принимает изменение по старой ревизии.

## Категории

| Категория GUI | Логирование |
|---|---|
| Блоки | BREAK/PLACE/INTERACT/USE и снимки BE |
| Контейнеры | Инвентари, AE2, GUI контейнеров и BE NBT |
| Сущности | Спавн, смерть, атаки, поездки, гибель/возрождение игроков и снаряды |
| Предметы | Бросок/поднятие/крафт/переплавка/использование/снаряды |
| Поезда Create | События и изменения поездов, включая действия механизмов и расписаний |
| Пушки | Записи с явным маркером `cannon` в дополнительной информации |
| Чат | Сообщения чата и поддерживаемые команды |
| Самолёты | Специальные события самолётов и события с подтверждённым источником самолёта |
| Вагонеточные штуковины | Типизированная история вагонеточных конструкций Create |
| Рюкзаки | События Backpacked |
| Подшипники | Конструкции Create bearing/clockwork |
| Другие конструкции | Поршни, шкивы, лифты и другие конструкции Create |

Фильтр поиска иногда включает несколько одинаковых низкоуровневых типов: например, `BLOCK_ENTITY_NBT_CHANGE` виден и среди блоков, и среди контейнеров; `PROJECTILE_HIT` — и среди предметов, и среди сущностей. Для таких событий отключение **любой** участвующей категории прекращает их запись. В фильтрах поездов и самолётов есть старые/общие записи, но отключение соответствующего захвата **не должно** запрещать все обычные события `ENTITY_SPAWN`: источник проверяется отдельно.

## Взаимодействие с настройками 2.1.23

Старые параметры `[createCapture]` продолжают действовать. GUI-переключатель может запретить дополнительно, но **не отменяет** уже установленный `logBearings = false` в TOML. Аналогично категории `logActorWork`, `logCargoTransfers` и `logLifecycle` остаются самостоятельными ограничениями.

Чтобы управлять всеми **типами Create** исключительно через GUI, оставьте в TOML `logMinecarts`, `logTrains`, `logBearings`, `logOtherContraptions` равными `true`, затем перезапустите сервер **один раз** после первоначальной правки конфигурации. После этого включение/выключение типов доступно непосредственно в GUI без рестартов.

## Безопасность и производительность

- Все действия проходят авторизацию **AvilixAuthCore** и проверку прав на сервере; клиент не определяет состояние.
- Для Create-категорий, блоков, контейнеров, AE2, чата и рюкзаков отсечение выполняется до дорогостоящих снимков NBT, если источник/тип известен.
- В центральном асинхронном приёмнике действует дополнительный фильтр перед копированием записей в очередь. Некоторые сторонние/общие события, когда источник становится известен только после действия, могут выполнять часть подготовительной работы до фильтрации.
- Записи успешного отката `CART_ROLLBACK` специально не подавляются: важно сохранить след административного действия.
- Для проверки TPS сравнивайте MSPT p50/p95/p99 и Spark/JFR до и после на **одинаковом мире и числе активных конструкций**; без этого улучшение не доказано.
- Для клиента и сервера используйте одинаковую версию мода **2.1.24**.
