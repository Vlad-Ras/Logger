# Chipped 4.0.2: преобразования инвентаря

Проверяемый контракт: Minecraft 1.21.1, NeoForge, Chipped 4.0.2. `ServerboundCraftPacket.Type` вызывает `WorkbenchMenu.craft(ItemStack, boolean)` на сервере. Меню содержит только слоты Inventory игрока; стандартный GenericMenuSnapshot намеренно исключает их и не подтверждает этот путь.

Отдельный optional wrapper охватывает нативный craft. При включённой категории предметов и разрешённом AuthCore захватываются отделённые снимки Inventory до/после, фактический прирост запрошенного результата, single/replaceAll, автор и отдельная идентичность владельца инвентаря. FakePlayer не объявляется реальным игроком-автором. Координаты принадлежат игроку; позиция верстака не выдумывается. Источник — `mod:chipped:workbench`.

`ITEM_TRANSFORM` — новый append-only тип в категории предметов, поиске и GUI. Сохраняются компоненты и расширенное количество. Пустое/отклонённое преобразование без прироста результата не создаёт строку. После no-op не вызывается повторная сериализация всего инвентаря. Перехват не добавляет ticking, capability lookup, обновление рецептов или повторный craft; исходное действие выполняется один раз. SNBT-кодирование отделённых данных остаётся в обычном фоновом pipeline.

У преобразования нет универсального отката. Обычный ITEM_CRAFT откатывается только удалением результата и не возвращает исходный материал; применять его к Chipped было бы частичным откатом. ITEM_TRANSFORM остаётся `not_rollbackable` до реализации отдельного полного контракта. Снимки не превращают этот открытый пункт в завершённый откат.

Mixin включается только для 4.0.2 после проверки сырого байткода: целевой класс, объявленное поле Inventory и точная сигнатура craft. Несовместимая/отсутствующая интеграция отключается до применения. Native smoke проверяет отсутствие target/field и подмену сигнатуры. Полное покрытие других модовых пакетов этим адаптером не заявляется.

Локальный запуск с точными JAR оператора:

```sh
./gradlew runServer -PchippedSmoke -Pneo_version=21.1.244 \
  -PchippedSmokeMods=/absolute/path/to/chipped-runtime
```

В отдельном каталоге должны находиться только нужные Chipped/ResourcefulLib/Athena JAR и требуемые ими зависимости. Этот параметр добавляет локальные файлы только в development runtime; файлы не встраиваются в Logger и не отправляются наружу. Для точного общего профиля Create/AE2/Framework применяются существующие compat-параметры.

Smoke проверяет настоящий native workbench, применение wrapper, single/replaceAll со стеком 1024, сохранение незатронутых предметов, отделённые полные снимки, автора, no-op, маску и запрет частичного отката. Он не обходит AuthCore и не доказывает production emit в настоящий ClickHouse.

25.10.2026 оба локальных прогона на NeoForge 21.1.244 завершились `CHIPPED_NATIVE_OK`; второй включает настоящий `ServerboundCraftPacket` consumer, отсутствие target/field и неверную сигнатуру. Присланный JAR отличается от официального Chipped `eqVowbGc` только `assets/chipped/lang/ru_ru.json`; код и игровые данные совпали. Использованы непосредственно JAR оператора.

Для проверки сырых контрактов уже существующих интеграций на точных файлах:

```sh
./gradlew testExactModpackPreflight -PexactModpackDir=/absolute/path/to/mods
```

Инструмент не добавляет переданные JAR в classpath JVM и не выполняет моды. Он сравнивает текущие mixin с предоставленным байткодом, а для платформенных классов использует выбранную среду NeoForge. Проверены 144 mixin и 92 предоставленных целевых класса в Create/Backpacked/AE2/Chipped/Immersive Aircraft. Это не подтверждает взаимодействие всех уже трансформированных mixin модпака или игровой охват остальных модов.

Общий проверяющий код учитывает только явно аннотированный `@Coerce Object` для ссылочного параметра. Отсутствие аннотации, примитив вместо ссылки, неверные число аргументов и возвращаемый тип по-прежнему отклоняются; эти случаи проверяются независимо от настоящих JAR.
