# Полное ТЗ AvilixLogger 2.1.35

Minecraft 1.21.1 / NeoForge. База: 2.1.34. Ветка: work/2.1.35-crash-recovery.

Источник требований — полный список пользователя из четырёх направлений, полученный 21 ноября 2026. Все четыре направления обязательны до выпуска. Старое состояние «реализация не начата» больше не соответствует исходникам: разработка идёт. Ни один незакрытый пункт нельзя считать автоматически выполненным по результатам другого теста.

Обозначения: **есть** — реализация присутствует; **частично** — остаются ограничения или приёмка; **открыто** — требуемого результата ещё нет. «Есть» не означает, что весь релиз принят.
