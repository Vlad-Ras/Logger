## Исправления

Writer удерживает вес строк до успешной записи на диск. Раньше неполная пачка могла удерживать весь лимит очереди и ждать flush timer, пока следующий producer уже заблокирован. Теперь batching consumer получает уведомление о заблокированном producer, забирает уже стоящие в очереди строки и публикует удерживаемую пачку без ожидания длинного таймера. Проверены ограничения по числу строк, байтам и единственная запись больше лимита. Резерв освобождается только после успешной записи журнала с прежними force/atomic publication. Уже накопленная пачка не дробится ради отдельных пробуждений.

При недоступной БД уведомления о новых файлах раньше прерывали retry delay. Теперь задержка 250/500/…/10 000 мс отсчитывается монотонными часами и сохраняется при обычных уведомлениях. Явная замена backend или shutdown прерывают ожидание; для нового backend задержка начинается заново. При повторной доставке сохраняются token и payload, файл удаляется только после успешного подтверждения.

Версия уведомления проверяется под тем же монитором перед ожиданием sender: сигнал между проверкой пустого журнала и переходом в wait больше не теряется. Таймер неполной пачки также использует System.nanoTime.

awaitVisible проверяет наличие первого JSONL через hasPending, не выбирая старейший файл из всего backlog при каждом опросе. Формат журнала не меняется; sender по-прежнему выбирает старейшие 64 файла. Это не индекс каталога.

## Открытые границы

Исправлена искусственная задержка неполной пачки. При продолжительной нехватке пропускной способности CPU/диска ограниченная lossless очередь всё ещё может блокировать producer, включая server thread. Не добавлены unlimited queue, overflow discard, inline encoding/I/O или ослабление AuthCore/категорий. Файловая запись и HTTP остаются в фоновых потоках; игровые тики и сериализаторы модов не менялись.

Нужны production AuthCore/configs, полный согласованный модпак и повторяемые A/B/A heap/GC/MSPT замеры, особенно ферма 8 пил + 8 активаторов с саженцами + portable storage interface. Исчезновение прежних ~60 000 мкс/тик Observable не объявляется. Native-блокер ручного stop Scguns 1.5 остаётся открытым. Поезда и вырезанный портальный переход в работу не возвращаются.
