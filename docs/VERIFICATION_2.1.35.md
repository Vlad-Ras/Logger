# Проверка кандидата 2.1.35 — 20 ноября 2026

Это результаты первого этапа, а не разрешение на производственный релиз. Исходники проверены локально; отправка новой ветки в GitHub пока заблокирована автоматической проверкой разрешений.

## Среда

Minecraft 1.21.1, NeoForge 21.1.219, Java 21, официальный Create 6.0.10 с проверенным SHA-512, AE2 19.2.12 и остальные зависимости штатного тестового набора. Полный пользовательский модпак и положительная авторизация через AvilixAuthCore не проверялись. Низкоуровневые игровые тесты не обходят авторизацию публичных команд; при отсутствии AuthCore мод штатно отключает серверные механизмы.

## Что прошло

- compileJava, compileCreateSmokeJava, testAsyncPipeline.
- testCreatePreflight, verifyMixinSafety, verifyObfuscatedJar.
- Существующие 10 проверок регрессии клиентских отчётов 2.1.34.
- Новые проверки планирования: точная цепочка состояний, разрыв истории, чужой игрок, полный NBT, отказ от дельты вместо снимка, связанная/непарная запись слота, отмена.
- Игровой CrashRecoverySmoke: забор, лестница, вода, обшивка Create; полный NBT и слоты сундука; повторное применение; изменённое содержимое; удаление без дропа; неизвестный блок; отсутствующий NBT; промежуточное сохранённое состояние; принудительный flush с сохранением исходного noSave; продвижение задачи по собственному бюджету.
- Полный существующий серверный Create smoke, клиентские отчёты и синтетическое профилирование. Сервер штатно завершился, JFR записан.
- Реальный клиент GUI: экраны истории, действий, подтверждения, результатов, справки, журнала, отчётов и настроек. Границы/перекрытия виджетов проверены при 320×240, 640×360 и 960×540. Снимки основного журнала, справки и действий просмотрены: используются существующие элементы и оформление. Клиент штатно завершился.

## Измерения и их границы

| Путь | Результат | Что измерялось |
|---|---:|---|
| Сеть | 12 871 байт | Кодирование предпросмотра на 512 маркеров; это размер payload, не мониторинг реального трафика |
| Сеть | 1 752 / 131 099 / 2 байта | 32 уведомления / порция файла лога / запрос телепорта в существующем smoke |
| TPS | 20,00 TPS; p50 11,265 мс; p95 18,157 мс | 60 тиков синтетической candidate-фазы существующего теста, 16 захватов на тик; не большой план восстановления и не онлайн 50 игроков |
| FPS | 59,2; p95 интервала 18,54 мс; p99 29,69 мс | 883 кадра GUI, программный OpenGL, ограничение около 60 FPS; не игровой мир полного модпака |
| Память клиента | 693,8 MiB в конце GUI-сценария | Занятая heap в одной точке; сама по себе не доказывает отсутствие утечки |
| Память сервера | Последняя heap после GC 3 274 165 968 байт; максимум после GC 4 013 964 712 байт | JFR всего тяжёлого набора Create, 101,43 с, 176 GC-пауз; не отдельно стоимость нового восстановления |
| Новый игровой сценарий | 1 203,27 мс; разница heap +5,01 MiB | Весь набор новых проверок, включая сохранения; не скорость восстановления произвольной постройки |

В JFR стенда есть тяжёлые выделения памяти и GC-паузы (максимум 221,85 мс). Эти данные нельзя объявлять доказательством нулевой нагрузки или освобождения всей памяти. Требуются отдельный длительный прогон восстановления, контроль удерживаемых объектов и замеры на полном модпаке.

Результаты синтетических baseline/candidate-фаз относятся к существующей методике стенда. По ним не заявляется ускорение 2.1.35 относительно отдельного запуска 2.1.34.
