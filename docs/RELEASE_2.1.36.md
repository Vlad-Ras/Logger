# AvilixLogger 2.1.36

Minecraft 1.21.1 / NeoForge 21.1.259 / Java 21. Отдельная ветка версии: `work/2.1.36`. Файл: `avilixlogger-2.1.36.jar`.

## Изменения относительно исправленной 2.1.35

1. Внутренняя версия мода изменена с 2.1.35 на 2.1.36; имя конечного JAR обновлено соответственно.
2. Проверки CI перенесены на ветку 2.1.36, имя артефакта и отчётов обновлено.
3. Игровой код, протокол и конфигурация сохранены. Минимальная NeoForge остаётся 21.1.259.

## Возможности ветки

- Логирование блоков, сущностей, действий игроков и поддержанных интеграций; поиск, GUI и отчёты клиентов.
- Обычные откаты и отдельное восстановление построек после краша с предпросмотром, состояниями/NBT/инвентарями, проверкой сцены и компенсацией при ошибке.
- Долговечный undo-WAL, восстановление незавершённой сцены при запуске и защита от повторного применения завершённых событий.
- Проверка сохранности предметов и закрытых переносов жидкости обычных баков Create; проверка связанных инвентарей игрока без записи в них.
- Выгрузка серверных логов, включая `logs/collision-forensics/diagnostics.log`, и открытие клиентской папки из GUI.
- Сохранены обфускация и штатная проверка AuthCore.

Полный перечень функций предыдущего выпуска: [2.1.35](CANDIDATE_2.1.35.md). Ограничения совместимости актуального модпака и положительной штатной авторизации остаются теми же; смена номера не объявляет их закрытыми.
